# Article Images

Place article hero images here.

Naming convention: `{slug}.jpg` — must match the `heroImage` frontmatter field in the corresponding article.

Example: for article `compost-tea.md` with `heroImage: /articles/images/compost-tea.jpg`, place the image at `compost-tea.jpg` in this folder.

Recommended dimensions: 1200 × 630px (16:9), optimized JPEG.
