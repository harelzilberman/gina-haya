# Mobile Assets

Place the following image files here before building:

| File | Size | Notes |
|---|---|---|
| `icon.png` | 1024×1024 | App icon (RGBA PNG) |
| `adaptive-icon.png` | 1024×1024 | Android adaptive icon foreground |
| `splash.png` | 1242×2436 | Splash screen |
| `notification-icon.png` | 96×96 | Android notification icon (white on transparent) |
| `moosh-avatar.png` | 256×256 | Moosh avatar — use the 🌕 moon illustration |

Background colour used in adaptive icon and splash: `#1a3a2a`
